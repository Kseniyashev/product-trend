Как читать

Никто не перезапускает убыточное: повтор запуска = продукт окупается, номер потока = сколько раз. Всего в срезе 207 окон продаж у 75 аккаунтов. Второй сигнал денег — рейтинг ГетКурса «Пьедестал»: 89 записей по психологии с 2023, поквартально (Дмитриева, PSY2.0, Бартон, Ameli Soul держатся кварталами).

Методика. Один срез = эвергрин экономики ниши, не тренды; velocity появится со второго месячного среза (ретро уже есть у Wordstat). Популяция — панель Кати (A+C, EN-панель D исключена), не рынок. Маппинги боль↔радар↔темы словаря — v1, руками. Метрика разрыва меряет упаковку, не наличие услуги. Конверсия плюс-постов смещена алгоритмом — сравнима между темами, не между аккаунтами.
